# 🚀 DevSpeedRun: Master Developer Journey

A comprehensive, production-grade learning roadmap and speedrun repository tracking software development mastery from core fundamentals to advanced architectural engineering.

---

## 📚 Phase 1: Python Mastery Curriculum

Phase 1 covers the complete Python language roadmap across 11 structured modules:

| Module | Directory | Topics Covered |
| :--- | :--- | :--- |
| **01. Python Basics** | `01_basics/` | Variables, primitive types, numeric operations, casting, f-strings, safe input, comparison operators, conditional branching |
| **02. Loops & Control** | `02_loops/` | While loops, sentinel patterns, while-else, for loops, range, enumerate, zip parallel iteration, nested loops |
| **03. Data Structures** | `03_data_structures/` | Lists, slicing mastery, mutation methods, search & removal, sorting strategies, tuples, namedtuples, dictionaries, set theory |
| **04. Comprehensions** | `04_comprehensions/` | List comprehensions with filters, dictionary & set comprehensions, nested comprehensions & matrix flattening |
| **05. Functions** | `05_functions/` | Signatures, return types, default arguments, `*args`, `**kwargs`, combined parameter signatures, LEGB scope, `nonlocal` |
| **06. Functional Python** | `06_functional/` | Lambda expressions, `map()`, `filter()`, `reduce()`, multi-criteria sorting, closures, factories, decorators, `functools.wraps` |
| **07. Exception Handling** | `07_exceptions/` | `try`/`except`, multiple exceptions, `else`/`finally` lifecycle, raising exceptions, assertion validation, custom exception classes |
| **08. File I/O & Context** | `08_file_io/` | File reading/writing/appending, custom context managers (`__enter__`/`__exit__`), `pathlib`, CSV processing, JSON handling |
| **09. Object-Oriented** | `09_oop/` | Classes & instances, `__init__`, class vs instance attributes, encapsulation, `@property`, `@classmethod`, inheritance, `super()`, polymorphism, magic dunder methods |
| **10. Advanced Python** | `10_advanced/` | Custom iterator protocol (`__iter__`, `__next__`), generators & `yield`, modern dataclasses, `collections` module (`Counter`, `defaultdict`, `deque`) |
| **11. Mini-Projects** | `11_mini_projects/` | CLI Todo Manager, OOP Banking Simulation, Unit Testing Suite with `unittest` |

---

## 🏃 Quick Start

Run any module directly with Python:

```bash
# Run the master script
python Holy_Claude.py

# Run any specific module
python 01_basics/01_variables_and_types.py
python 09_oop/10_magic_dunder_methods.py
python 11_mini_projects/02_banking_simulation.py
```
